Update materials across posts, rails and infill. Apply material changes without rebuilding the geometry.

Store named presets or copy and paste settings to repeat configurations across projects.

03 / Workflow

Simple to start.
Detailed when you need it.

Four straightforward steps, with additional settings available whenever you need more control.

  1. 01Select edgesDraw or select the path where the railing should run.
  2. 02Choose a systemPick from seven railing and fencing construction styles.
  3. 03Set dimensionsEnter height, spacing, placement and material options.
  4. 04Generate and refineBuild the geometry, then reopen settings to modify the result.

Editing notes

Parameter changes regenerate the tool-created geometry, which can replace manual edits made inside generated groups. Saved material selections refer to materials in the current SketchUp model; unavailable materials may revert to Default in another model.
