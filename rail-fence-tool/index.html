01 / Horizontal Cable RailingCrio Rail & Fence Tool

Built around real geometry

Draw the path.
Define the system.

Select connected SketchUp edges, load one of seven preset configurations and generate a complete rail or fence assembly. Control post spacing, rails, glass or other infill, materials and alignment — then return to Detailed Settings whenever you need to make changes.

01 / Construction systems

Seven systems.
One workflow.

Browse the seven included style thumbnails. Choose a starting configuration, then adjust its dimensions, construction and finishes in Detailed Settings.

02 / Release features

Built for control.

Load a style from the preset gallery for a quick start, or open Detailed Settings to refine geometry, placement and materials.

01 / PATHS

Build from selected edges

Turn selected SketchUp edges into connected railing and fence runs, including multi-corner and sloped paths.

02 / PRESETS

Seven starting styles

Choose from seven built-in styles with thumbnail previews, then customize each system using Detailed Settings.

03 / CONSTRUCTION

Configure every component

Set overall height, post dimensions and spacing, rails, infill and the materials used by generated components.

04 / TOP RAIL

Continuous top rails

Create a connected top-rail group across the fence, with mitered or rounded corner treatment for round handrails.

05 / GLASS

Glass and clamp controls

Configure glass panel sizing, clearances and clamp placement based on the generated post positions.

06 / ALIGNMENT

Position the whole system

Place railings inside, outside or centred on a path, with available orientation and setback settings.

07 / ELEVATION

Follow the selected path

Build along the elevations of the selected edges, including staircase-to-landing transitions. Posts use Follow Path base elevation.

08 / CORNERS

Control corner posts

Use the adjustable corner-angle threshold to distinguish meaningful turns from small freehand path changes.

09 / REUSE

Save, update, repeat

Save named configurations, reopen existing fence settings and use precise numeric inputs to refine and regenerate results.

03 / Workflow

Simple to start.
Detailed when you need it.

Four straightforward steps, with additional settings available whenever you need more control.

  1. 01Select edgesDraw or select the path where the railing should run.
  2. 02Choose a systemPick from seven railing and fencing construction styles.
  3. 03Configure the partsAdjust posts, rails, infill, alignment and materials with precise numeric inputs.
  4. 04Generate and refineBuild the geometry, then reopen settings to modify the result.
